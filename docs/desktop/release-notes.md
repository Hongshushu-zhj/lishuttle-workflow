# 桌面版 0.1.0 开发记录

日期：2026-11-16。开发分支：`codex/desktop-app`。

## 本版范围

- Electron 桌面窗口、受限原生文件选择与日志保存、单实例和任务退出监管。
- Vue 工作空间：六阶段导航、持续日志、环境与路径、运行历史与帮助。
- 复用既有 Python 业务操作，保留项目修订、文件版本、锁、快照、备份、结果证据与会话语义。
- 内置 Python，安装资源只读与开发/正式用户数据分离，Windows x64 NSIS 安装。
- 限定范围的内容识别扫描、手动路径、旧配置预览导入、可选结束历史导入、偏好恢复。

## 交付边界

LiShuttle 引擎、第三方库、业务数据及其使用授权不包含在本软件中。真实计算性能、所有引擎功能及不同电脑的数据适配，需使用合法真实数据在目标环境验收。开发阶段仅使用临时夹具验证计算流程，不执行用户真实项目。

本版没有自动更新、跨平台安装包和云端同步。安装包尚未配置发布者代码签名，正式外发前需签名。构建时可能访问依赖源；安装完成后的应用运行不依赖在线服务。

验证命令、实际通过项和仍需人工确认的项目见 acceptance.md；首次配置与恢复说明见 usage.md。
