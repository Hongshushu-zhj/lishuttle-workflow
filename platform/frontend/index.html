正在获取运行状态

VS、CMake、Ninja 和 MSVC 环境脚本属于本机全局配置，所有项目和本地脚本共用。首次打开会自动搜索并保存空缺项；换项目无需重复配置。重新检测只补空缺，已有值可手动修改后保存。

把鼠标放到参数上，这里显示说明

工作流程

    按顺序准备，随时返回修改。已有程序可直接使用。

    01项目与环境选择项目 · 确认目录与资源待确认展开收起
    项目目录

    尚未选择项目

    在此选择或切换项目，确认目录与资源位置；配置保存在当前项目。

    按目录内容识别，不限制项目名称。添加后保存在本机列表。

    打开项目时自动检测本项目的预设和资源目录，确定的值直接填入，多个候选可下拉选择或手动填写。每项下方显示来源；保存后仅对当前项目生效。本机工具链请在上方全局入口配置。

    02程序准备复用已有程序，或编译所选配置待确认展开收起

    修改源码并保存后，点击「编译所选配置」会调用本机 CMake / MSVC，按所选项目预设增量编译并链接受影响的目标；没有变化时可能无需重新编译。请在操作日志中确认本次编译成功，然后重新装配并进行运行前检查。

    已有匹配程序可直接继续；需要编译时再配置工具链。

    03任务与输入功能、地图、工参与运行配置待确认展开收起

    选择地图场景与工参任务，确认本次输入。

    地图与场景
    任务文件

    任务设置

    装配后同步运行 XML 名称、输出子目录和 Visual Studio 启动项；修改后需重新装配。
    运行功能 -f

    输入文件

    先选择工参任务
    选择对应地图后生成本地路径；生成副本的 name 与任务名一致，原文件、计算参数及注释保留。特殊索引、场景和路测等路径可在下方明确修改，预览后确认。
    修改本地资源路径

    根据当前项目、地图和工参任务自动填入本机路径，可手动调整。区域文件统一使用上方选择。留空恢复自动值；不会修改源 XML。

    选择地图与任务运行配置后识别本地路径。

    选择工参及地图后可保存；对应关系仅在当前项目生效。
    查看与编辑所选工参 CSV

    修改后请保存，再切换文件或运行。

    整列设置：
    选择工参后自动带入同一文件，点击加载查看内容
    04装配与确认核对来源与目标，生成运行配置待确认展开收起

    装配前请核对目标程序、输入来源和任务名称。

    资源与装配

    清理平台历史配置
